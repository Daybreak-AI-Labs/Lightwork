# Lightwork glossary

Lightwork uses these words in its screens and guides. Older technical names
may still appear in exported records or detailed reports.

| Term | Meaning |
| --- | --- |
| **Task** | One piece of work you ask Lightwork to complete. |
| **Run** | One attempt to complete a task or carry out a workflow. A task may have more than one run. |
| **Result** | The saved answer or work product from a finished task. Review it before relying on it. |
| **Workspace** | A named place for a team's people, tasks, settings, and saved work. Some older records call this a *tenant*. |
| **Specialist** | A prepared AI role for a kind of work, such as reviewing a contract or preparing a report. Older records may call its definition a *pack*. |
| **Agent** | An AI worker set up for a particular role or set of instructions. Its saved instructions do not grant access to a service or approve its actions. |
| **Workflow** | A reusable way to start work from a saved instruction or template. |
| **Flow** | A visual sequence of connected steps. A flow can include choices, repeated work, service actions, and pauses for a person. |
| **Draft** | A saved version that is still being prepared. Saving a draft does not publish it or start work. |
| **Published version** | The reviewed version made available for people or schedules to use. New edits normally create a separate draft. |
| **Connection** | A saved sign-in or service key that lets Lightwork contact another service. A connection does not grant every person or workflow permission to use it. |
| **Approval** | A person's decision about a specific proposed change or action. Review the exact details; an approval applies only within the scope shown. |
| **Copilot** | Lightwork's in-product guide. It can answer supported questions and open reviewed controls; it cannot bypass your access or confirmation. |
| **Learning example** | A past, permission-checked example that may help improve a procedure when its owner allows that use. It is not proof that the next answer will be correct. |
| **Spending limit** | A boundary on paid work. A per-task limit, a workspace limit, and a service limit can be different controls. |
| **Activity log** | A record of selected changes and decisions. It is useful for review but does not prove that every outside service completed an action. |
| **Episode** | An older technical name for one run of a task. |
| **Goal** | An older technical name for a task. |
| **Envelope** | A technical record of the allowed actions and limits for a worker. It does not override the person's current access or a required approval. |
| **Compartment** | A technical name for a restricted area used to keep one kind of information or work separate. |
| **HALT** | The emergency stop that prevents new work from starting until an authorized person clears it. Clearing it does not undo work already in progress or changes already made elsewhere. |
| **Shield** | Lightwork's checks on requests, proposed actions, and answers. A check can reduce risk; it does not guarantee that an answer or outside service is correct. |

If a screen uses a word you do not recognize, open **Help** for guidance on that
page or see [Troubleshooting Lightwork](troubleshooting.md).
