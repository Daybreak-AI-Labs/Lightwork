01 Autonomous Shoring

Move a whole function, not one task at a time.

Offshore, nearshore, onshore: every sourcing decision moved work to another building. Autonomous Shoring moves a business function such as accounts payable, tier-1 support or contract review onto AI agents you run yourself, and keeps the whole operation on one screen: what's in scope, how it's tracking against target, what's waiting for a person, and what it costs compared with doing it by hand.

01
Find the work
Ekko spots the work your team repeats and drafts a workflow for it. Optional, and off until you turn it on.
02
Build the team
Switch on the specialists for the department, describe a new one in plain English, or show Lightwork a person doing the job.
03
Hand it over
Move each business area from planning, to trying it out alongside your team, to running with people on the exceptions.
04
Prove it
Every target measured from finished work, every exception on one desk, and a savings estimate from your own rates.

02 What it does

Everything a team needs to hand off real work.

Lightwork is one platform: a chat that gets things done, a team of AI specialists behind every request, and the plumbing to connect them to your tools, your channels and your workflows.

Chat

Ask for the result, get the result

Describe what you need in plain language and get the deliverable back. Threads keep the context, and you can attach files, dictate, or add guidance while it works.

Teams

A team behind every request

An orchestrator plans the work, hands parts of it to researcher, coder, writer and verifier agents working in parallel, checks what they return and gives you one answer.

Agent Factory

Hire from a job description

Describe an agent in plain English, or paste a job description, and Lightwork drafts the specialist: its job, the tools it may use and its limits.

Discovery

Ekko finds what to automate

Ekko notices work people repeat across the apps you allow and turns it into workflow drafts you review. It never records the screen, keystrokes or document contents. Optional.

Workflows

Workflows and automations

Build multi-step workflows in a visual designer, start them on a schedule, a webhook or an email, and import existing ones from n8n, Make, Workato, UiPath or Power Automate. Optional.

Connections

Plugs into your stack

A large registry of REST and GraphQL connectors plus any MCP tool server. A change to an outside system waits for a person to approve it.

Channels

Works where your team talks

Slack, Microsoft Teams, email, WhatsApp, SMS, Telegram, Discord, Signal, Matrix and voice, so people can hand work over without opening another app.

Learning

Gets better at your work

Successful runs become proposed skills; once a person admits one, later runs use it. Cortex keeps your documents, decisions and lessons in one search.

Proof of work

Shows how it got there

Replay any task, compare branches side by side, or turn a run into a captioned walkthrough. GitHub issues can even become pull requests.

03 Specialists

Specialists for every department, ready on day one.

Lightwork ships with a library of specialist agents, each with a fixed job, the tools it is allowed to use and a step-by-step workflow. Switch on a department instead of writing prompts, and when nothing fits, describe the job and Lightwork drafts a new specialist for you to review.

04 Your operation, live

See every specialist's work as it happens.

The dashboard shows what's in flight, what was delivered and what's waiting for a person, with a Copilot on every page that explains what you're looking at. The same work is available from the command line, your editor and the API.

05 The company brain

Cortex. Everything your company knows, in one mind.

One search across your documents and data with citations, the skills learned on your work, the lessons from past runs, the record of every decision, and what outside agents contributed. Skills a person admits are used in later runs, so the work keeps getting better.

06 Your models, your tools

Any model. Every interface.

Models

Pick a model for each role

Anthropic, OpenAI, Azure, Bedrock, Vertex, Gemini, DeepSeek, xAI, Moonshot and OpenRouter, or run fully local through Ollama, vLLM, TGI or any OpenAI-compatible server. Settings lists the models your keys can reach.

Interfaces

Wherever you work

The web dashboard with Copilot, the lightwork command line, a desktop app and editor integrations in preview, an MCP server any agent can call, a REST API, and a GitHub Action that runs a task in CI under a spending cap.

07 Built to be trusted

Powerful, and still yours to control.

Every action passes the same checks before it runs and lands in a signed record you can verify. Changes to outside systems and other high-risk actions wait for a person by default, and you decide how much each specialist does on its own.

09 Get started

Install it from source in a few minutes.

Lightwork is alpha software. No packaged release is published yet, so the supported path is a clone of the repository. You need Git and Python 3.11 or 3.12; Docker or Podman is recommended for running commands in a container.

macOS · Linuxfrom a fresh terminal
git clone https://github.com/Daybreak-AI-Labs/Lightwork
cd Lightwork
python3 -m venv .venv
. .venv/bin/activate
python -m pip install --upgrade pip
python scripts/install_release_cohort.py --core-extra release-runtime,evidence-analysis
lightwork doctor
lightwork dashboard

The dashboard opens at http://127.0.0.1:8765 and walks you through first sign-in and connecting a model provider. Open /shoring to set up your first business area. lightwork doctor checks the installation and suggests a fix for anything it flags.

Windows PowerShell commands and post-install checks are in the install guide.
