Self-hosted AI agents with governance built in.

Lightwork is an open-source multi-agent runtime. Give it a goal: an orchestrator splits the work across specialist sub-agents on the models you choose, checks their output, and records each step in a signed audit log. Permission controls and the spending limits you set bound what the agents can do.

What it does

Multi-agent orchestration

An orchestrator decomposes a goal, runs specialist sub-agents such as a researcher, coder, writer and verifier in parallel, and checks their output before returning a result.

Permission controls

Role-based access, capability tokens, per-tool access lists, consent gates and a kill switch bound every agent action. Agent Shield screens prompts, tool calls and outputs, and enterprise mode adds an egress lock on the agent's outbound network paths.

Signed audit log

A signed, hash-chained, append-only audit log that you can verify with lightwork audit verify and export to a SIEM.

Your choice of models

Per-role model routing across Anthropic, OpenAI, Gemini, Amazon Bedrock, Azure OpenAI, OpenRouter, Ollama, vLLM and other providers, including self-hosted models.

Spending limits

Administrators can set per-task dollar, wall-clock and tool-call limits, and separate organization allowances.

Reviewable learning

Lightwork captures experience and proposes new skills and workflow changes. Human review, activation and rollback of each change are recorded.

Install

Python 3.10 to 3.12 and Git. On macOS or Linux:

git clone https://github.com/Daybreak-AI-Labs/Lightwork
cd Lightwork
python3 -m venv .venv
. .venv/bin/activate            # Windows: .venv\Scripts\activate
python -m pip install --upgrade pip
python scripts/install_release_cohort.py --core-extra release-runtime,evidence-analysis
lightwork doctor
lightwork dashboard             # serves the dashboard at http://127.0.0.1:8765

The source install guide covers Windows PowerShell and checking the installation.
