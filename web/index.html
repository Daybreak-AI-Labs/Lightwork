01 Autonomous Shoring

The fifth way to source work.

Offshore, nearshore, reshore, onshore: each one moved a function to another building and another team. Autonomous Shoring moves it onto AI agents you run yourself, and you keep the whole operation on one screen.

Sending a function out

  • Months of transition before the provider's team is up to speed.
  • Monthly reports and sampled QA tell you how it went.
  • More volume means more hiring and another round of training.
  • What the team learned walks out with the people.

Autonomous Shoring

  • Switch on the specialists, or show Lightwork the job, and try it alongside your team.
  • Live service levels from every finished item, on target, at risk or missed.
  • More volume means more specialists, with the same targets and exception desk.
  • What it learns stays: skills you approve and a company memory that keeps them.

How Autonomous Shoring works

03 People on the exceptions

The agents do the routine. Your people make the calls.

A payment run, an invoice that doesn't match, a refund over the limit: anything that needs a decision lands on one desk, sorted by business area, one click from the task behind it.

As trust builds, let each specialist do more on its own, from watching, to suggesting, to asking first, to acting.

04 The platform

Everything underneath, ready for any work.

Autonomous Shoring runs on the same platform your team can use for anything else: one chat, a team of AI specialists behind every request, and the plumbing to reach your tools, your channels and your workflows.

Chat

Ask for the result, get the result

Describe what you need and get the deliverable back. Threads keep the context; attach files, dictate, or add guidance while it works.

Teams

A team behind every request

An orchestrator plans the work and hands it to researcher, coder, writer and verifier agents in parallel, then checks what comes back.

Agent Factory

Hire from a job description

Paste the job description you'd post, or describe the agent in plain English, and review the specialist Lightwork drafts.

Ekko

Finds what to automateoptional

Notices work people repeat across the apps you allow and turns it into workflow drafts. It never records the screen, keystrokes or document contents.

Workflows

Processes that run themselvesoptional

A visual designer, triggers from a schedule, a webhook or an email, and imports from n8n, Make, Workato, UiPath and Power Automate.

Connections

Plugs into your stack

A large registry of REST and GraphQL connectors plus any MCP tool server. Changes to outside systems wait for a person's approval.

Channels

Works where your team talks

Hand over work from Slack, Microsoft Teams, email, WhatsApp, SMS, Signal or a phone call, without opening another app.

Proof of work

Shows how it got there

Replay any task, compare branches side by side, or turn a run into a captioned walkthrough. Label a GitHub issue and get a pull request.

08 Built to be trusted

Powerful, and still yours to control.

Every action passes the same checks before it runs and lands in a signed record you can verify. Changes to outside systems and other high-risk actions wait for a person by default.

09 Get started

Open source. Running in a few minutes.

Lightwork is alpha software under the Apache License 2.0. Install it from source with Git and Python 3.11 or 3.12, open the dashboard, connect a model, and set up your first business area at /shoring.

Windows commands and post-install checks are in the install guide. Questions go to Discussions; contributions follow the contribution guide.

macOS · Linuxfrom a fresh terminal
git clone https://github.com/Daybreak-AI-Labs/Lightwork
cd Lightwork
python3 -m venv .venv
. .venv/bin/activate
python -m pip install --upgrade pip
python scripts/install_release_cohort.py --core-extra release-runtime,evidence-analysis
lightwork doctor
lightwork dashboard
