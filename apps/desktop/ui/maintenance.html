If an installation fails

    
Windows Installer restores the previous application when an upgrade fails before completion. Repair reinstalls the current version. These actions do not undo work or restore workspace data.

    
A protected completed upgrade can return to its exact prior release and saved local state using the reviewed controls above. Upgrades without a saved recovery point require an administrator's compatible recovery plan.
