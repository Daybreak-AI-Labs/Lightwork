What a verb does

Suspend revokes the principal's capability (native: the next tool call under it is denied; external: the trust entry is revoked too). Contain is the security plane's incident response: the subtree is revoked and the incident recorded. Attenuate narrows an external agent's ceiling and never widens it. Halt stops the whole fleet at the next tool boundary. Nothing here adds enforcement; it drives the enforcement that already exists and reports only what it confirmed.
