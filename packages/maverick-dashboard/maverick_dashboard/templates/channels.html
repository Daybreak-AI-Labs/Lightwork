How to set one up

  1. Choose a chat app below and tick Turn on.
  2. Paste the details that app gives you. Each field says where to find it. They're stored securely and never shown again. Leaving a field blank keeps what's saved.
  3. Press Save, then Test connection. Changes take effect the next time Lightwork starts.
  4. Message Lightwork from that app. Requests are handled the same way as tasks started here, and replies come back in the same conversation.
