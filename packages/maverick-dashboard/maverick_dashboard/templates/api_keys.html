What the key may do

Only the scopes your role allows are offered. A key can never do more than you can. Both operator scopes allow every operator action; the admin scope also includes operator and audit actions. No key can create, rotate or revoke access keys.

Service accounts

A service account is a named identity for a program. It holds keys and a role but cannot sign in. Disabling one stops all of its keys at once.
