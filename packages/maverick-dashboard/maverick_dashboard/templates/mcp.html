What is MCP?

MCP (Model Context Protocol) is an open standard for connecting AI agents to outside tools — file storage, GitHub, databases and more. Each server you add here gives your agents a new set of tools they can use on your behalf. Learn more at modelcontextprotocol.io.

For administrators: tool naming

Servers expose tools over a JSON-RPC channel; Lightwork consumes them as mcp_<server>__<tool>.
