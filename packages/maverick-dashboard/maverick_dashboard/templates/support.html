Help and diagnostics

Prepare a redacted report of this installation's versions, readiness checks and recent failures. Review it here, then download the same report to share with your support contact.

What the report will include

  • Installed Lightwork component versions, Python/runtime version, operating-system platform and machine type.
  • The absolute Python executable and Lightwork data-root paths, plus whether the data root exists and is a directory.
  • License customer, tier, status, enabled suites and expiry; the current client/workspace binding identity.
  • Whether a provider is configured, the names of providers Lightwork recognizes, and readiness of workspace identity, safety controls and trusted agents.
  • Counts of recent failures grouped into fixed categories. Job identifiers, job types and raw error messages are excluded.
  • Configuration shape: hashed configuration-key names, boolean and numeric settings, and collection sizes. Configuration text values are replaced with presence markers.
  • A random support reference and the time the report was prepared.

Document text, prompts, URLs, customer document filenames, passwords, tokens, credential payloads and raw job errors are excluded. Preparing the report stores an encrypted preview on this installation for up to ten minutes. Nothing is sent automatically.
