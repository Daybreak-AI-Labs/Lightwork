Help and Diagnostics

Make a report about this installation for your support contact. Private details are removed. You review it here first, then download exactly what you reviewed.

What the Report Includes

  • Which versions of Lightwork and its parts are installed, and the kind of computer and operating system.
  • Where Lightwork and its data are installed on this computer (the folder locations), and whether the data folder exists.
  • Your licence: customer, plan, status, included areas and expiry, plus which workspace this installation belongs to.
  • Whether an AI provider is set up, which providers Lightwork recognizes, and whether workspace identity, safety controls and trusted agents are ready.
  • How many recent failures happened, grouped into general kinds. Task names, task types and raw error messages are left out.
  • The general shape of your settings: on/off switches, numbers and how many items are in each list. Setting names are scrambled and text values are replaced with “set” or “not set”.
  • A random support reference and the time the report was made.

Document text, prompts, web addresses, customer file names, passwords, access keys and raw task errors are left out. The report preview is kept, encrypted, on this installation for up to ten minutes. Nothing is sent automatically.
