Trust boundary

What this workbench proves

  • Tenant, operator, key reference, key version, retention, and quotas are resolved by the server.
  • Only exact boolean, opaque value-ID, or unique value-ID-list matches are supported.
  • Source changes make an index stale; search fails closed until an administrator rebuilds it.
  • Profile identifiers returned by search remain governed identifiers, not proof of identity or consent validity outside the pinned source record.
  • Local integrity does not prove live customer-estate completeness or external acceptance.
