Global Opt-Out

Publish one versioned mobile and email experience against an exact public client, property, publication, receipt policy, and origin or service authority. Public submission creates a real opt_out privacy-rights request; this control plane retains only result digests.

Closed boundary

What this page does—and does not—prove

  • The server independently resolves the public client and active publication/policy before every configuration mutation.
  • Public configuration and submit contracts accept no tenant, property, profile, origin, service, or policy selector.
  • Submission stores a case-reference digest and verified signed-result digest, never the raw DSAR case or identity payload.
  • Local workflow tests do not establish live mobile, email, connected-device, or customer-estate acceptance.
