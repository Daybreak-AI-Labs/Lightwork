Why create a workspace?

A workspace walls off one client or team. Everything it produces lives in its own home — so one client's evidence can never mix with another's:

  • Its own records — a separate operating record and run history; work done for one workspace is invisible to the rest.
  • Its own knowledge — uploaded documents and customized agents stay inside the workspace that owns them.
  • Its own budget — a daily spend limit and usage ledger per workspace, so one client can never burn another's budget (and usage rolls up cleanly for billing).
  • Its own access — people can hold a different role per workspace, and a workspace can be suspended without touching the others.

One client per workspace is the rule of thumb: separate books, separate evidence, one roster to run it all from.
