Loading file history…

Turn on file protection before running a task. Lightwork then keeps an encrypted copy of each file before a task changes it, and refuses the change if it can't keep that copy. Earlier work can't be recovered this way.

Turn off file protection

Future tasks will change files without keeping a copy first, so their changes can't be put back from this page. Copies already kept for earlier tasks stay, and can still be restored here.

What this can restore

Only files changed by this task's own file tools on this computer. Up to 100 files per run, 8 MB each and 32 MB in total. Long previews may be shortened, but every file is fully checked before it is put back. Stop this task, and any other task using the same folder, before restoring. If a restore is interrupted, you can retry exactly the same restore. Tasks run on another computer, and very old runs, can't be restored here.

What changed during this task

See each file in this task's work folder as it was before the task first changed it, next to how it is now. Lightwork keeps only those two points, so in-between versions can't be compared. Looking changes nothing.

What this can show

Only files inside this task's own work folder that the task changed with its file tools while "Keep a copy before files change" was on. Files reached through a shortcut link, or kept outside the work folder, are never shown. Up to 100 files, each up to 256 KB and 4,000 lines; files that aren't text are listed without their content. Commands the task ran are not included.
