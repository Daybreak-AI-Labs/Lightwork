About this page's safeguards

The list can be incomplete while a cloud account is still being read. A provider accepting a change does not prove the change happened: Lightwork marks it as needing confirmation until a fresh read of the provider shows the result. Agent names, credentials and prompts never leave your cloud accounts; Lightwork only keeps anonymous references. Two different people must review and approve a Databricks mapping before it is used.
