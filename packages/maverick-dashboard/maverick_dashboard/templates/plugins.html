For administrators: enabling plugin installs

Plugins are Python packages declaring maverick.tools, maverick.channels, maverick.skills, or maverick.personas entry points. For one-click install from here, list approved packages under [plugins] installable in ~/.maverick/config.toml and set MAVERICK_ALLOW_PLUGIN_INSTALL=1. Or install on the host: 

pipx inject maverick-agent <package-name>
