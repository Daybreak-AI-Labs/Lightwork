            Comparison verification details

              Restore this workspace

              Restoring replaces workspace files with the selected snapshot and removes files created afterwards. A verified safety snapshot is kept first. Other workspaces, shared administration and external stores are excluded. The exact application build must match the snapshot; a different build requires a reviewed compatibility procedure.

              Live restore is refused if spending records, budget holds, protected external-action history or database files differ from the snapshot. An administrator must reconcile that history first. You can still export the snapshot and test it in a temporary workspace.

              Protect an application update

              Windows installation changes affect every local workspace and shared administration. Lightwork pauses before capturing a verified pre-upgrade snapshot and retains the exact signed old installer. Rolling back a completed upgrade replaces the application and all local state with that snapshot; newer work is kept in a separate safety snapshot. External services are excluded.

              A completed update can be rolled back here only when accounting, protected external-action history and database files still match its original snapshot. New spending, budget holds, action outcomes or database changes require coordinated reconciliation before returning to the old release.

              Review a signing identity transition

              Ordinary updates keep the same signing identities. A publisher or update-key change requires the default-off Signing identity transition setting, a dual-signed exact-release bridge, and your separate approval. Save the proposed review file from Install & updates, then select it here. No new identity is trusted merely by selecting a file.

              Copy this short-lived authorization into Install & updates in the desktop app menu. It permits the reviewed action on this computer only; do not share it. No installation or restoration starts on this page.

              Retire an unused authorization or obsolete recovery point

              This permanently deletes the selected point's local installers, snapshots and logs, and cancels any unused authorization. Review your retention requirements first. Unfinished operations and rollback for the installed application remain protected.
