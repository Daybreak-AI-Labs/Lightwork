What this protects

    Separate recovery requirements

        Recovery key

        Keep this key in a secure place separately from your snapshots. It is required to verify and restore them. This app keeps a private local copy; a lost computer needs your separate key copy.

        Use an existing recovery key

        Import is available only before a key has been configured here.

        Encryption key custody

        Keep a separate copy of local encryption keys

        This download contains sensitive plaintext key material that may unlock several workspaces. Keep it in your offline vault or secrets manager, separately from snapshots. Remote key-service and environment keys require their existing custodian. Shared keys are never replaced by a workspace restore.

        Snapshots

        Snapshot archives contain sensitive workspace data and may include encryption keys. Store exported copies securely outside this computer.

        Restore checks verify file hashes, sizes and local SQLite integrity. They do not certify application-level decryption, cross-file business invariants or external systems.

        Retire a local snapshot

        Export and verify an external copy first if retention is required. This deletes only the selected local archive. Snapshots retained for a current or recent restore cannot be removed.

        Import a saved snapshot

        Maximum archive size: 256 MiB compressed and 1 GiB expanded. Only a snapshot signed with the configured recovery key and bound to this workspace can be imported.

        Restore this workspace

        Restoring replaces workspace files with the selected snapshot and removes files created afterwards. A verified safety snapshot is kept first. Other workspaces, shared administration and external stores are excluded. The exact application build must match the snapshot; a different build requires a reviewed compatibility procedure.

        Live restore is refused if spending records, budget holds or database files differ from the snapshot. An administrator must reconcile that history first. You can still export the snapshot and test it in a temporary workspace.

        Protect an application update

        Windows installation changes affect every local workspace and shared administration. Lightwork pauses before capturing a verified pre-upgrade snapshot and retains the exact signed old installer. Rolling back a completed upgrade replaces the application and all local state with that snapshot; newer work is kept in a separate safety snapshot. External services are excluded.

        A completed update can be rolled back here only when accounting and database files still match its original snapshot. New spending, budget holds or database changes require coordinated reconciliation before returning to the old release.

        Copy this short-lived authorization into Install & updates in the desktop app menu. It permits the reviewed action on this computer only; do not share it. No installation or restoration starts on this page.

        Retire an unused authorization or obsolete recovery point

        This permanently deletes the selected point's local installers, snapshots and logs, and cancels any unused authorization. Review your retention requirements first. Unfinished operations and rollback for the installed application remain protected.

          Recent retirement receipts

          The most recent 100 signed retirement receipts are kept locally. They do not contain the deleted snapshots or installers.
