            Technical details

              Restore This Workspace

              Restoring puts the workspace back exactly as it was in the chosen snapshot and removes anything made afterwards. A checked safety copy of the current workspace is saved first. Other workspaces, shared settings and outside services are not affected. The snapshot must come from this exact version of Lightwork.

              A restore is refused if spending records, budget holds, records of actions in outside services, or database files differ from the snapshot. An administrator must sort that out first. You can still download the snapshot and test it safely.

              Review Restored Work Before Going Back to Normal

              Nothing listed here runs by itself. Requests that were waiting must be retired and asked for again. For work that may have reached an outside service, check that service and record what you found.

                For chat-app messages and reading positions, look at the chat service itself, then answer the questions for each item. Your check must be from the last 15 minutes. Old messages are never sent again automatically. If you can't tell what happened, leave the item unresolved.

                This version of Lightwork can't safely sort out at least one restored item. Stay in recovery mode and create a support report (private details are removed).

                Protect an App Update

                On Windows, installing an update affects every workspace and the shared settings on this computer. Lightwork pauses, saves a checked copy of everything, and keeps the previous installer. Going back to the previous version replaces the app and everything on this computer with that copy; newer work is kept in a separate safety copy. Outside services are not affected.

                You can go back only while spending records, records of outside actions and database files still match the saved copy. If they changed, an administrator must sort that out first.

                Review a change of publisher

                Normal updates come from the same publisher as before. If the publisher or its update signature changes, the setting that allows this must be turned on, the update must be signed by both the old and new publisher, and you must approve it here. Save the review file from Install & updates in the desktop app, then choose it below. Choosing a file does not trust anything by itself.

                Copy this short-lived code into Install & updates in the desktop app menu. It only allows the action you reviewed, on this computer; don't share it. Nothing is installed or restored from this page.
