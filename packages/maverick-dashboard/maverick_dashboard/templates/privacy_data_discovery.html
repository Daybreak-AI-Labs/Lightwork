  • Unsupported formats: unstructured discovery currently accepts JSON, JSON-LD, XML, CSV, HTML, and plain text. PDF, Office, images, archives, audio, and video are reported as unsupported rather than silently treated as complete.
  • Timing limit: scans check their deadline between items. A provider request already in progress may take longer than that deadline.
  • Where changes go: approved classifications are queued for the configured Lightwork data map. Changes to external providers remain disabled until separately authorized.
  • Automatic retries: these remain off until enabled for this installation and workspace. They update only the configured Lightwork data map; they do not scan providers or prove complete coverage.

6. Inventory, reports, findings, and diff

Inventory and diffs contain only classifications, counts, and keyed digests. “No findings” is never represented as proof of absence.

7. Submit a finding for review

The proposal records who prepared it and which finding it uses. Submitting a proposal does not change the data map.

8. Independent approval

The approver must be a different signed-in person. Only approval of a current finding can update the configured data map or processing-activities record.

9. Deliver, reconcile, and maintain the governed data map

Automatic update status. Availability shows whether updates are enabled and running for this workspace, including interrupted work awaiting recovery. Checking status does not start a scan or contact a provider.

Lightwork records the user and workspace responsible for each update. These actions use fingerprints and enforce processing limits; they do not write to external providers or establish successful use with a live provider.
