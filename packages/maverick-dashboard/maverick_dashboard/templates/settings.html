Choose which pages each role sees. Unchecking a box removes the page from that role's navigation and blocks direct access to it. A dash means the role's permissions can't reach that page at all (visibility can never grant more than a role's permissions allow — change the user's role on the Users page instead). Admins always keep Settings and Users, so you can't lock yourself out. Roles only apply when sign-in is configured; in local single-user mode everyone sees everything.
