Privacy Rights Consumer Delivery

Authenticated operator control plane for short-lived, one-time capabilities bound to an exact closed rights case and exact response package.

A raw consumer capability appears only in the first mint response. Copy it immediately; Lightwork stores only its digest and cannot replay it. This surface never accepts a tenant, actor, consumer subject, object locator, object credential, or encryption-key value. It exposes no consumer redeem, server-grant claim, object-byte, network, provider-write, or list operation.

Production composition gates

The stock runtime re-resolves the exact closed case and package, requires a separately authenticated public profile plus independent reauthentication, and reads only the pinned active package from the encrypted governed-document vault. It checks the package digest and vault authority before grant issue, before byte consumption, and again before returning the response.

Fail-closed seam: operator minting remains unavailable until the deployment supplies an independent operator-to-consumer identity mapping. The case/package authority is never used as consumer identity proof.
