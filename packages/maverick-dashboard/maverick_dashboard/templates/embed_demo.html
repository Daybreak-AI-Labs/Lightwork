Embedded analytics

Put a live snapshot of your workspace — spend, activity, and outcomes — on any internal page, like a team wiki or status hub.

This is the analytics card, running live against this workspace. It shows total spend, the cost trend, and work by status, and it updates every time the page loads:

Add it to another page

Copy the code below and give it to whoever looks after the page where you want the card to appear (for example your wiki or intranet team). It already points at this dashboard. Ask your administrator for an access key if your workspace requires sign-in.

Technical details (the code to paste) 
<script src="http://YOUR-DASHBOARD:8765/static/lightwork-analytics.js"></script>
<lightwork-analytics
    endpoint="http://YOUR-DASHBOARD:8765"
    token="YOUR-ACCESS-TOKEN"></lightwork-analytics>

Replace YOUR-ACCESS-TOKEN with the access key, or remove that line if your workspace runs without sign-in.

Good to know

  • Works on pages served alongside Lightwork. For security, browsers only let the card load data from pages on the same address as this dashboard (or behind the same reverse proxy). A page hosted elsewhere will show a "blocked" message rather than your data.
  • Treat the access key like a password. Anyone who can view the page with the card can see the key, and it grants the same access as the dashboard itself. Only add the card to pages whose audience you trust with that access. If your workspace runs without sign-in, leave the key out entirely.
  • View-only. The card only reads data — it can't change anything, and it shows the error plainly if a request fails.
  • Already added somewhere? Cards added before Lightwork was renamed keep working unchanged.
