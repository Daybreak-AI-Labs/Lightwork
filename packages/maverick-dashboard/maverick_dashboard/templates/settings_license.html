About this page's safeguards
  • Only installation administrators can use this page.
  • A license file is installed only after its signature checks out against this server's trusted license keys.
  • Replacing the installed license always asks you first.
  • The signing key is read from your server's secret store. It is never shown, saved in settings or written to the activity record.
  • Every license change and every new key pair is written to the activity record, with who made it.
